# SPEC — JB OSINT: гибридный режим (Termux + Server Side)

Источник: общее ТЗ пользователя от 22.11.2026 (JB OSINT, репозиторий `Djygas/jb-osint`).
Режим работы: продолжение после HEAD `b4ce9526` (22.11.2026 10:16 МСК).

## Цель

Сохранить 100 % работоспособность приложения без интернета и без сервера и добавить
опциональные ускорители:

1. **Локальный слой Termux** — Python-скрипты на телефоне (Crawl4AI, MarkItDown, RAE),
   диагностика окружения, безопасный мост через `RUN_COMMAND`, авто-скрипт настройки.
2. **Reverse API Engineer (RAE)** — генерация «Своего модуля» из трафика браузера:
   локально через Termux и на сервере с обязательным маскированием PII.
3. **Серверный слой** — FastAPI-шлюз (`/scrape`, `/ai/analyze`, `/api/discovery`,
   `/api/v1/rae/generate`), Docker, ключ `X-API-Key`, rate limit.
4. **Каскад с откатом** — Local → Termux → Server; при недоступности сервера приложение
   не падает, а сообщает «Режим ограниченной функциональности».

## Что уже есть в репозитории (базовая линия, не переписываем)

- Локальный ИИ-аналитик (Hugging Face/OpenAI-совместимые провайдеры, `Assistant.kt`).
- Сшивка сущностей (`EntityResolver.kt`), профиль объекта, поведенческий анализ.
- `report-core`: PDF 20+ страниц со шрифтом Inter, HTML, XLSX, JSON, CSV.
- «Свои модули» (`CustomModules.kt`), автопоиск страницы ключа (`AutoSetup.kt`),
  диагностика и починка модулей.
- Автономные агенты, Telegram-парсеры (TeleSint/Telelog/Funstat), фото-поиск.

## Стек и ограничения

- Android: Kotlin 2.0.21, Compose, minSdk 26, targetSdk 35, AGP 8.7.3.
- Сервер: Python 3.12, FastAPI, Docker Compose, Nginx.
- Сборка Android — **только в ASCII-пути** (`C:\jbosint\jb-osint`): AGP не собирает
  проект в пути с кириллицей. `GRADLE_USER_HOME` тоже должен быть ASCII, иначе
  тестовый JVM не находит `GradleWorkerMain` (argfile `@C:\Users\????\...`).
- Секреты — только `.env` / `keystore.properties` / `EncryptedSharedPreferences`.
  В код, git и чат не попадают.
- PII перед отправкой на внешние LLM маскируется (`***`). Жёсткое требование NDA.

## Решения

- **Termux-мост без произвольного кода:** приложение запускает только встроенную
  диагностику и скрипты из белого списка в `~/JB_OSINT_Scripts/`; имя скрипта
  валидируется, путь ограничен домашней папкой Termux.
- **Результаты команд** — через `PendingIntent` и `BroadcastReceiver` (официальный
  механизм Termux `RUN_COMMAND`), без чтения приватных файлов Termux.
- **Импорт `api_client.py`** — через SAF (`ACTION_OPEN_DOCUMENT`), потому что Android 11+
  не даёт читать общую папку Termux напрямую.
- **Серверный RAE** не отправляет сырой HAR в LLM: сначала маскирование, потом анализ.
  По умолчанию внешняя LLM выключена (`ALLOW_EXTERNAL_LLM=0`) и работает
  детерминированный генератор клиента из HAR.
