## JB OSINT 1.21.6 (debug)

Первый релиз, собранный из объединённого дерева проекта: в репозитории теперь лежит всё — Android-приложение (`app/`), ядро отчётов (`report-core/`), сервер (`server/`) и CI. Отдельные архивы (`JB-OSINT-1.21.2`, `JB-OSINT-1.21.5`, `jb-osint-termux-rae-server`) больше не нужны: их содержимое целиком вошло в этот код, а поверх него — правки 1.21.6.

### Что внутри 1.21.6

- **OCR сканов на сервере.** `server/app/ocr.py`: tesseract для PDF без текстового слоя и для картинок; клиент помечает такие факты как прочитанные OCR.
- **Досье документов.** Импорт TXT/DOCX/HTML/PDF, поиск по словам (AND), хранение в приватной папке, серверный `/documents/extract` (MarkItDown → stdlib → pypdf).
- **Сверка фактов.** `/ai/analyze`: противоречия по объектам и полям (включая email) — сравнение идёт по исходным значениям, маскирование только перед внешней LLM.
- **JS/Cloudflare через Crawl4AI.** `/scrape` с `render=true`: страница рендерится headless-браузером, если обычный HTTP заблокирован или текста меньше 200 символов.
- **Серверное чтение страниц.** Фолбэк на `/scrape`, когда локальная загрузка падает; в отчёте факт помечается «Получено: серверный режим».
- **Termux-мост.** RUN_COMMAND, диагностика, авто-скрипт настройки, белый список скриптов.
- Отчёты: PDF/HTML/XLSX/CSV через `report-core`.
